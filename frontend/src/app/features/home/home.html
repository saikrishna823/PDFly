How your files are handled

Processed locally

Tools marked On your device run entirely in your browser. Your file is never uploaded — once a tool has opened, it keeps working even if you go offline.

Temporary server processing

Some conversions need software that can't run in a browser. For those, your file is sent over an encrypted connection, processed in memory or a temporary folder, and deleted as soon as the result is sent back. Files are not kept afterwards, and PDFly has no accounts and no analytics.
